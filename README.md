# Agent Architecture & Security Skills

Skills para opencode especializados en arquitectura de agentes y seguridad OWASP.

## Instalación

```bash
# Copiar skills al directorio de opencode
cp -r skills/* ~/.agents/skills/
```

## Skills incluidos

- **agent-development**: Creación y configuración de agentes
- **owasp-top-10**: Revisión de vulnerabilidades OWASP Top 10
- **owasp-security-review**: Auditoría de seguridad
